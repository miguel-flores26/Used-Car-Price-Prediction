# Used-Car-Price-Prediction
This is a beginner group project I led for the Data Science Club at UC Davis. We used a dataset of ~4,000 used car listings from Kaggle to build a model that predicts used car prices. The bulk of the work was in preprocessing and feature engineering as we cleaned engine specs, transmission type, and exterior color while creating new columns such as an indicator for electric vehicles. We evaluated several models and found XGBoost with a log-price transformation to perform best, achieving a cross-validated MAE of $5,584 and R² of 0.84. The final model was used to create a prediction function that estimates price from car details like year, mileage, engine, and more.
